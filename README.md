🔐 AES Secure Encryptor

AES Secure Encryptor is a lightweight and secure Android application designed to encrypt and decrypt text using the industry-standard AES-128 (GCM mode) encryption algorithm.

Built with modern Android technologies and a clean UI, this app provides fast, offline, and reliable cryptographic protection for your sensitive messages.

✨ Features

🔒 AES-128 encryption (GCM mode)

🔓 Secure decryption with secret key

⚡ Fast and lightweight performance

📋 One-tap copy to clipboard

🎨 Clean and modern Material UI

📡 Fully offline – no internet required

🔐 No data collection or storage

🛡 Security

The app uses:

AES/GCM/NoPadding

Random IV generation for each encryption

Secure key handling

Local device processing only

All encryption and decryption operations are performed directly on your device. No data is transmitted or stored externally.

🎯 Use Cases

Protecting private messages

Securing sensitive information

Learning and experimenting with AES encryption

Developer utility for cryptography testing
